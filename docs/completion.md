# rp completion
Shell completion — print a completion artefact for wiring.
Users can wire completion without knowing install paths: install.sh does it
automatically, and this command is the manual path (plus the reinstall and
upgrade paths). The artefacts under completions/ are GENERATED by
scripts/gen-completion.sh from the grammar spec (`rp _complete-spec`) and
ship in the release tarball.

```
rp completion <bash|zsh>
```

## Commands

- [`rp completion bash`](completion-bash.md) — Print the bash completion artefact to stdout.
- [`rp completion zsh`](completion-zsh.md) — Print the zsh completion artefact to stdout.
